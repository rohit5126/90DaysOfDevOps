## Global information tracker(Git) is a versioning control tool, it creates a file system which stores versions of code and it can be recovered after file deletion.

### Task 1: Install and Configure Git
```bash
# Verify Git is installed on your machine
'git --version'

# Set up your Git identity — name and email
'git config --global user.name rohit5126'
'git config --global user.email rohit5126kumar@gmail.com'

# Verify your configuration
'git config --list'
```

### Task 2: Create Your Git Project
```bash
# Create a new folder called devops-git-practice
'mkdir devops-git-practice && cd devops-git-practice'

# Initialize it as a Git repository
'git init'

# Check the status — read and understand what Git is telling you
'git status'

<<output
On branch master  #shows on which branch we are working
```
