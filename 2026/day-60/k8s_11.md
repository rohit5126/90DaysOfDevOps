# Capstone: Deploy WordPress + MySQL on Kubernetes

## Task 1: Create the Namespace (Day 52)

```
kubectl create namespace capstone

kubectl config set-contet --current --namespace=capstone                                                                  
# to set default nmespace to capstone

```

## Task 2: Deploy MySQL (Days 54-56)

```
apiVersion: v1
kind: Secret
metadata:
  name: cap-sec 
  namespace: capstone
type: Opaque
data:
  MYSQL_ROOT_PASSWORD: cm9vdA==
  MYSQL_DATABASE: d29yZHByZXNz
  MYSQL_USER: Y2Fwc3RvbmU=
  MYSQL_PASSWORD: Y2Fwc3RvbmU=
```
```
apiVersion: v1
kind: Service
metadata:
  name: mysql-svc 
  namespace: capstone
spec:
  type: ClusterIP
  clusterIP: None
  selector:
    apps: mysql
  ports:
    - port: 3306
      targetPort: 3306

---

apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: mysql-state 
  labels:
    apps: mysql
spec:
  replicas: 1
  serviceName: mysql-svc
  selector:
    matchLabels:
      apps: mysql
  template:
    metadata:
      labels:
        apps: mysql
    spec:
      containers:
        - name: mysql
          image: mysql:8.0
          ports:
            - containerPort: 3306
          env:
            - name: MYSQL_ROOT_PASSWORD
              valueFrom:
                secretKeyRef:
                  name: cap-sec
                  key: MYSQL_ROOT_PASSWORD
            - name: MYSQL_DATABASE
              valueFrom:
                secretKeyRef:
                  name: cap-sec
                  key: MYSQL_DATABASE
            - name: MYSQL_USER
              valueFrom:
                secretKeyRef:
                  name: cap-sec
                  key: MYSQL_USER
            - name: MYSQL_PASSWORD
              valueFrom:
                secretKeyRef:
                  name: cap-sec
                  key: MYSQL_PASSWORD
          resources:
            requests:
              cpu: 250m
              memory: 512Mi
            limits:
              cpu: 500m
              memory: 1Gi

          volumeMounts:
            - name: mysql-pvc
              mountPath: /var/lib/mysql
  volumeClaimTemplates:
    - metadata:
        name: mysql-pvc
      spec:
        storageClassName: "standard"
        accessModes: ["ReadWriteOnce"]
        resources:
          requests:
            storage: 1Gi
            

```

`kubectl exec -it mysql-state-0 -- mysql -u capstone -pcapstone -e "SHOW DATABASES;"`
to verify the db.

## Task 3: Deploy WordPress (Days 52, 54, 57)

```

apiVersion: v1
kind: ConfigMap
metadata:
  name: mys-config
  namespace: capstone
data:
  WORDPRESS_DB_HOST: mysql-state-0.mysql-svc.capstone.svc.cluster.local:3306
  WORDPRESS_DB_NAME: capstone
```

```
apiVersion: apps/v1
kind: Deployment
metadata:
  name: wordpress-deployment
  labels:
    apps: wordpress
  namespace: capstone
spec:
  replicas: 2
  selector:
    matchLabels:
      apps: wordpress
  template:
    metadata:
      labels:
        apps: wordpress
    spec:
      enableServiceLinks: false 
      containers:
        - name: wordpress
          image: wordpress:latest
          ports:
            - containerPort: 80
          env:
            - name: WORDPRESS_DB_HOST
              valueFrom:
                configMapKeyRef:
                  name: mys-config
                  key: WORDPRESS_DB_HOST
            - name: WORDPRESS_DB_NAME
              valueFrom:
                configMapKeyRef:
                  name: mys-config
                  key: WORDPRESS_DB_NAME
            - name: WORDPRESS_DB_USER
              valueFrom:
                secretKeyRef:
                  name: cap-sec
                  key: MYSQL_USER
            - name: WORDPRESS_DB_PASSWORD
              valueFrom:
                secretKeyRef:
                  name: cap-sec
                  key: MYSQL_PASSWORD
          resources:
            requests:
              cpu: 250m
              memory: 512Mi
            limits:
              cpu: 500m
              memory: 1Gi
          readinessProbe:
            httpGet:
              path: /wp-login.php
              port: 80
            initialDelaySeconds: 60  
            periodSeconds: 10    
          livenessProbe:
            httpGet:
              path: /wp-login.php
              port: 80
            initialDelaySeconds: 60   # Wait 10s before checking (gives WP time to start)
            periodSeconds: 10          # Check every 10s      

```


**Note- make sure yu database name is secret and configmap is same**
**also check db name before creating wordpress by "kubectl exec -it mysql-state-0 -- mysql -u capstone -pcapstone -e "SHOW DATABASES;""**

Both pods are now running.

## Task 4: Expose WordPress (Day 53)

```
apiVersion: v1
kind: Service
metadata:
  name: wp-service
spec:
  type: NodePort
  selector:
    apps: wordpress
  ports:
    - port: 80
      targetPort: 80
      nodePort: 30080
```

Can you see the WordPress setup page? **yes**

## Task 6: Set Up HPA (Day 58)

```
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
  name: wordpress-hpa
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: wordpress-deployment
  minReplicas: 2
  maxReplicas: 10
  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        type: Utilization
        averageUtilization: 50
```
