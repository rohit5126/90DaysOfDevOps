## GitHub CLI: Manage GitHub from Your Terminal

### Task 1: Install and Authenticate

**in your terminal run below script**

```bash
(type -p wget >/dev/null || (sudo apt update && sudo apt install wget -y)) \
	&& sudo mkdir -p -m 755 /etc/apt/keyrings \
	&& out=$(mktemp) && wget -nv -O$out https://cli.github.com/packages/githubcli-archive-keyring.gpg \
	&& cat $out | sudo tee /etc/apt/keyrings/githubcli-archive-keyring.gpg > /dev/null \
	&& sudo chmod go+r /etc/apt/keyrings/githubcli-archive-keyring.gpg \
	&& sudo mkdir -p -m 755 /etc/apt/sources.list.d \
	&& echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/githubcli-archive-keyring.gpg] https://cli.github.com/packages stable main" | sudo tee /etc/apt/sources.list.d/github-cli.list > /dev/null \
	&& sudo apt update \
	&& sudo apt install gh -y
```

to verigy PGP keys before gh installation

`curl -fsSL -o - https://cli.github.com/packages/githubcli-archive-keyring.gpg | gpg --show-keys`

### Task 2: Working with Repositories

**create a repo using CLI**

`gh repo create --public --add-readme`

```bash
✓ Created repository rohit5126/githubcli on github.com
  https://github.com/rohit5126/githubcli
```
**clone the repo to your local**

`gh repo clone githubcli`

**View details of one of your repos from the terminal**

`gh repo view <repo_name>`

**list all your repo**

`gh repo list`

**Open a repo in your browser directly from the terminal**

`gh repo view --web`

**Delete the test repo you created (be careful!)**

```bash
#refresh your authorization to get access to delete repo 

gh auth refresh -h github.com -s delete_repo

gh repo delete rohit5126/githubcli --yes

```

### Task 4: Pull Requests

**Create a branch, make a change, push it, and create a pull request entirely from the terminal**

`gh pr create -t "added issue.md" -l "app_issue" -b "added info for ongoing issue"`

```bash

Creating pull request for devops into master in rohit5126/devgitops

https://github.com/rohit5126/devgitops/pull/5
```

**List all open PRs on a repo**

`gh pr list`

**View the details of your PR — check its status, reviewers, and checks**

`gh pr view 5`

**Merge your PR from the terminal**

from master branch....
`gh pr merge 5`
```bash
gh pr merge 5
Merging pull request rohit5126/devgitops#5 (added issue.md)
? What merge method would you like to use? Create a merge commit
? Delete the branch locally and on GitHub? No
? What's next? Submit
✓ Merged pull request rohit5126/devgitops#5 (added issue.md)
```

**What merge methods does gh pr merge support?**
1. Merge commit
2. Rebase commit
3. squash commit

**How would you review someone else's PR using gh?**
`gh pr review 5`
