```
-cluster
-vpc
-subnets(private and public)
-nodegroups
-ebs_csi #for volume persist
-IAM integration

```

-coredns 
-http_route
-metrics-server #enables kubectl top and HPA

## Task 3: Provision the EKS Cluster

**Make sure you have the required tools:**

```
terraform --version    # >= 1.0
aws --version          # AWS CLI v2
kubectl version --client  #to connect to cluster and work with it
helm version   #to install argocd, observality tools directly inside cluster.
```

**Configure AWS credentials:**

```
aws configure

#add iam access key ID, and access key and add default availability zone.
```

**Intialize and apply**

```
terraform init

terraform plan

terraform apply -auto-approve  #it will take around 15-20 mins.

terraform output

```

## Task 4: Connect to Your Cluster

**connect your kubectl with cluster**

`aws eks update-kubeconfig --name devboard --region eu-north-1`

**Verify the connection:**

`kubectl get nodes`
`kubectl cluster-info`

## Task 5: Deploy the AI-BankApp Manually

**install envoy gateway using helm**
```
helm install eg oci://docker.io/envoyproxy/gateway-helm \
  --version v1.8.3 \
  -n envoy-gateway-system \
  --create-namespace
```

**apply files one by one in correctl order**

```
cd EKS-terrform-k8s

kubectl apply -f namespace.yml
kubectl apply -f 01-secrets-and-config.yaml
kubectl apply -f 02-serviceaccounts.yaml

kubectl apply -f 03-postgres-statefulset.yaml
kubectl rollout status statefulset/postgres -n devboard-app

kubectl apply -f 04-backend.yaml
kubectl rollout status deployment/backend-deployment -n devboard-app

kubectl apply -f 05-frontend.yaml
kubectl rollout status deployment/frontend-deployment -n devboard-app

kubectl apply -f 06.gateway.yml
kubectl apply -f 07-network-policies.yaml  


```

`kubectl get pods -n devboard-app`  #to check if everything is up

```
kubectl get gateway -n devboard-app → PROGRAMMED: True, real ELB hostname assigned
kubectl get httproute -n devboard-app → route present and accepted
kubectl describe networkpolicy node-frontend-policy -n devboard-app → confirms updated selector
curl against the new ELB hostname → confirms end-to-end traffic flow through Envoy Gateway to the frontend

```
