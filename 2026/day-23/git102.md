### Task 1: Understanding Branches

**A branch in GitHub (and Git) is a lightweight, movable pointer to a specific commit in your project's history. 
It allows you to isolate your work from the main codebase**

**we should not commit everything into a main branch as it would disrupt the ogoing worklow and if there is any issue with the latest commit, the man applicaion will be 
affected.**

**Head is a pointer to the latest commit of the branch**

**When you switch branches in version control systems like Git, your working directory and files are dynamically updated to match the commit history of the new branch**
