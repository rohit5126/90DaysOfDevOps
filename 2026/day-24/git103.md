**What is a fast-forward merge?**
fast forward merge happend when ther is verly less change or 1 file change or 1 commit.

**When does Git create a merge commit instead?**
git creats merge commit when ther are multiple commits or changes in the feature branch.

**What is a merge conflict?**
Merge conflict happens when you change same line in a file in two diffrent branches and then try to merge them. git does not know which line should be kept
in the file and which should be removed, so it craetes merge conflict. we have to manually resolve the conflict to merge the branches.
